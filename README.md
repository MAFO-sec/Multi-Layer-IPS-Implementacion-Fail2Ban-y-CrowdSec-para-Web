# Multi-Layer-IPS-Implementacion-Fail2Ban-y-CrowdSec-para-Web
Laboratorio de ciberseguridad defensiva que implementa un IPS multicapa. Incluye detección de ataques de fuerza bruta, monitorización en tiempo real con Apache Superset y mitigación automatizada mediante Fail2Ban (reglas locales) y CrowdSec (inteligencia colectiva). Todo orquestado con Docker y Nginx Proxy
